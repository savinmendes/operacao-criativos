## Como usar
- Pergunta de estratégia → abra o dossiê do tema, vá direto a «Onde os convidados DISCORDAM» e «Transferência», depois confira o trecho na ficha/transcrição pelo #episódio e timestamp.
- Todo número é **declarado** pelo convidado, não benchmark. O canal vende ferramenta para esse mercado (viés de sobrevivente).

## Lacunas da base inteira (valem para todos os dossiês)
- **COD / pagamento na entrega:** 0 episódios. Nenhum limiar de ROAS, CPA ou ROI considera entrega, recusa, devolução ou frete.
- **Latam / espanhol:** só menções (#153, #160, #128). Nada de Chile, Colômbia, México, Guatemala ou Romênia.
- **Venda 1-a-1 pós-paga por WhatsApp, público 50+:** nenhum caso; os closers da base são de high ticket pré-pago.
- **Espiritualidade:** nenhum episódio.
- Para cobrir isso, alimentar a base com outras fontes (Fluxo 0 da skill `consultor-de-cases`).
