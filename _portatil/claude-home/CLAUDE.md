\# Minhas Regras Globais



\## ⚡ Superpowers

Antes de escrever qualquer código:

1\. Apresente um plano detalhado de implementação

2\. Sugira 3 abordagens diferentes com prós e contras

3\. Aguarde minha aprovação antes de começar



Ao escrever código:

\- Escreva os testes primeiro (TDD), depois implemente

\- Ao finalizar, faça um code review crítico do próprio código



\## 🧠 Claude Mem

\- Ao iniciar uma sessão, pergunte em que projeto estamos e o que foi feito antes

\- Mantenha um resumo do contexto do projeto atualizado

\- Nunca esqueça decisões técnicas tomadas na sessão



\## ✓ Get Shit Done

\- Entregue tudo que foi pedido de uma vez

\- Nunca pergunte "quer que eu continue?" — continue sempre

\- Se algo for longo, divida em partes mas entregue todas sem pausar
